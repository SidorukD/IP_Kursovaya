# Атлас мира

Онлайн-каталог стран с краткими справками, поиском и фильтрами. Сделан на HTML, CSS, JavaScript и Bootstrap 5.

## Возможности

- каталог из 13 стран;
- фильтр по континенту;
- поиск по названию, официальному названию и столице;
- фильтр по континенту;
- сортировка по названию, населению и площади;
- отдельная страница страны с краткой справкой;
- избранное, которое сохраняется в `localStorage`;
- адаптивная вёрстка для компьютера и телефона.

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Каталог стран, поиск, фильтры и сортировка |
| `country.html` | Справка о выбранной стране |

Страница страны открывается по коду:

```text
country.html?code=JP
```

## Структура проекта

```text
AtlasWorld/
├── index.html
├── country.html
├── css/
│   └── atlas.css
├── js/
│   ├── countries.js
│   └── catalog.js
├── assets/
│   └── atlas.svg
└── README.md
```

- `js/countries.js` — массив стран и все справочные данные;
- `js/catalog.js` — поиск, фильтры, сортировка, страница страны и избранное;
- `css/atlas.css` — оформление и адаптивные правила.

## Технологии

- HTML5;
- CSS3;
- JavaScript (ES2015+);
- Bootstrap 5.3 (CDN);
- `localStorage` для избранного.
